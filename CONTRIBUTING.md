# Contributing

This repository contains companion documentation and selected references for a review article.

Useful contributions include corrections to bibliographic metadata, repairs to broken links, clearer explanations of a framework component, and relevant reading suggestions.

For a literature suggestion, please provide the title, authors, year, DOI or stable publisher/preprint link, the relevant section, and a short explanation of its relevance. Distinguish published articles from preprints. New references added to this repository should be identified as supplementary reading if they were not cited in the review.

Open a GitHub Issue for a suggestion or submit a pull request for a concrete edit. Changes to companion notes should remain distinguishable from the claims and bibliography of the journal article.

Original documentation contributions are made under the repository's [CC BY 4.0 license](LICENSE). Link to third-party publications and resources using their original sources.
