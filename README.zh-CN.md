## 核心问题

长期气候变化预估需要理解自然气候过程，也需要解释未来排放路径如何形成。气候风险会影响政策、投资、技术替代和适应行为，这些响应进一步改变排放，并反作用于气候系统。

本文基于地球系统模式、RCPs/SSPs 情景体系、综合评估模型和人类−地球系统耦合研究，讨论人工智能如何为这一反馈过程提供可学习、可约束、可诊断的方法工具。

综述围绕三条主线展开：

1. **天气人工智能向气候人工智能的拓展。** 梳理天气预报、长期气候模拟、参数化、神经算子和混合建模的进展，强调长期稳定性、气候统计态、外部强迫响应与物理一致性。
2. **行为−排放−气候的模块化反馈。** 将气候压力、行为与政策响应、排放与强迫变化、气候物理核心以及约束与解释连接起来。
3. **可观测、可校准、可检验的研究路径。** 以气溶胶和中国污染治理实践为切入口，讨论历史回算、政策冲击和反事实实验如何检验反馈链条。

## 框架与方法

| 核心模块 | 研究任务 | 文中讨论的方法 |
| --- | --- | --- |
| 气候状态表征 | 从气候状态、极端事件和暴露中提取风险信号 | 多源数据融合、表示学习、极端事件分析 |
| 行为与政策响应 | 刻画响应强度、时滞、区域差异和适应行为 | 因果推断、贝叶斯模型、序列模型、强化学习 |
| 排放与强迫响应 | 将行为和政策变化映射为排放、浓度与辐射强迫 | 排放清单融合、代理模型、物理约束 |
| 物理气候核心 | 模拟外部强迫变化下的气候响应 | 地球系统模式、简化气候模型、神经算子、混合模型 |
| 约束与解释 | 检查物理一致性、因果结构与不确定性 | 守恒约束、反事实分析、不确定性分解 |

上述内容是综述提出的概念框架和研究方向。评价应同时覆盖物理可信度、行为可信度、守恒性、长期稳定性和不确定性分解。具体说明见 [Framework notes](docs/FRAMEWORK.md)。

## 为什么关注气溶胶与中国场景？

气溶胶对经济活动和污染治理响应较快，具有明显的区域差异，并通过辐射及云相互作用影响气候。这使其成为连接政策、排放、空气质量和区域气候响应的重要观测入口。

中国污染治理实践提供了政策变化、区域异质性及多源观测相结合的研究场景，可用于分层检验行为响应、排放与强迫映射以及气候响应。温室气体和土地利用变化仍是长期预估的重要组成部分。
